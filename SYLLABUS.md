# Syllabus

35 units across A1 → A2 → B1, each mapped to stable grammar topic ids. Topic
ids are what `data/grammar/<topic>.md` files and `Exercise.topic` refer to, so
they must not change once content is built against them.

**Ordering:** unchanged from the build spec (§5). No reordering has been
applied, so there is nothing to justify yet. Validation against the CEFR
descriptors and the Goethe-Zertifikat exam specifications happens in phases 4
and 5, when each unit's explanation is sourced — any change made then will be
recorded in the *Deviations* section below with its reason.
